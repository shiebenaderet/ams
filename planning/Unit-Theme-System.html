Unit Theme System — Color & Typography

A distinct, readable identity for each of the eight units — built for Google Docs, coherent across the year, and never overwhelming. Fonts below are rendered live in the actual typeface.

Three rules keep eight themes from becoming chaos:
  • One body font all year. Every unit shares Lato for body text, so the reading experience is identical everywhere — only the accents change. This is what keeps it calm.
  • One signature heading font per unit. Each unit gets a single display typeface for its titles and headers, chosen to match the unit's mood. That's the "typographical theme."
  • A three-color palette per unit: a deep (titles, chip fills), an accent (subheads, rules, callout bars), and a pale tint (backgrounds, table shading). Dark text always sits on light — readability first.
Every font here is available in Google Docs' font picker. If you'd rather keep it even simpler, pick one heading font for the whole year and let color alone carry each unit — the palettes still work.

Using these in Google Docs

Everything here maps straight into the GDoc Suite — no add-ons needed.

  1. Add the fonts once. In any doc, open the font menu → More fonts, and add Lato plus the eight heading fonts. They'll then appear for every document.
  2. Set the unit's two fonts. Use the unit's heading font for Title/Heading styles and Lato for Normal text. Save as a template per unit if you like.
  3. Apply the palette by hex. Anywhere you pick a color (text, highlight, table cell, border), choose Custom and paste the hex code — e.g. deep for headings, accent for rules, tint for table shading.
  4. Reuse a header block. Build one titled header table in the unit's theme, then copy it into every handout for that unit so they all match instantly.
A readability note: headings use each unit's deep shade (dark enough for strong contrast), accents are reserved for rules, subheads, and chip fills rather than long text, and body copy is always near-black Lato on white or a pale tint. That's what keeps the sheets easy on the eyes even in black-and-white photocopies — the deeps stay legible in grayscale.
